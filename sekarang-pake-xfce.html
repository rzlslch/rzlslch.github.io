sekarang pake xfce
linux ⚬ 08 September 2026

Sekarang saya pake xfce. Padahal sebelumnya saya adalah penganut kultus kurcaci. Kenapa?

Review dulu. First impression, snappy, fast, beneran cepet, dan praktikal. Sejauh ini belum ada komplain. Bener-bener praktikal. Memang untuk default, ga ada fitur “fancy” seperti desktop environment modern lain. Pake xfce itu kayak balik ke 90an dan 2000an awal. Jaman-jaman windows 95-98, mentok XP. Tapi emang esensi dari desktop environment kan application launcher, jadi ya ga ada yang kurang. Kebanyakan desktop environment modern itu fokusnya kalo ga ke eyecandy ya window management. Buat saya, eyecandy itu ga penting dan window management itu masalah habit. Jadi pake xfce itu ya kayak nostalgia dan second nature aja, migrasi nya ga kerasa. Dan sekalian saya theming ke tema yang mirip windows 95/98. Biar tambah kerasa nostalgia nya.

Terus kenapa kok pindah?

Sebenernya pindah ini bukan masalah di desktop environment nya sendiri. Tapi karena troubleshooting. Jadi ya, akhir-akhir ini saya stres, terus sakit sampe sempet ngamar beberapa hari. Saya ambil keputusan, refreshing nya dibanyakin. Jadi saya sering ngegame lagi. Kondisi komputer saya itu, SSD cuman 250GB (SSD sekarang mahal banget, waktu build PC ga sempet kebeli). Tapi saya ada 3 HDD, 320GB, 1TB, dan 4TB. Game saya disana. Kalo main itu ada minor stutter gitu. Meski FPS nya tinggi terus, tapi tetep ngerasa ada stutter2 gitu. Ga enak banget.

Iseng lah saya. Posisi nya waktu itu saya masih pake Gnome, jadinya wayland. Saya sering denger (lihat lebih tepatnya) di diskusi2 kalo ngegame lebih enak pake xorg. Saya install lah xfce. Desktop Environment langsung pakai yang masih pake xorg. Terus nyoba main game. Ilang dong minor stutter nya. Bukan hilang secara total, tapi hampir mendekati perfect lah. Lah, ngefek ternyata. Saya kira wayland vs xorg tentang gaming ini uda ga ada issue. Mungkin ini juga kepengaruh saya ngegame di HDD, tapi if it works, it works. Saya pindah ke xfce. Dan saya juga setup nya minimal, saya pake xfce as is, paling ngatur2 panel sama theme aja.

    application menu

Apps, hampir semua pake default xfce:

Dan terakhir, saya masih pake gdm bawaan Gnome, Gnome nya sendiri belum saya uninstall.
